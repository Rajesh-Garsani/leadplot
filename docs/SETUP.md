# Connections setup

Start run.py and sign in. Click Connections. Settings save to the local backend immediately; app.py and worker.py also read the new values without restart. You still keep your dashboard password and session secret in .env, generated by setup_local.py.

## Apify

Paste one or more API tokens, one per line. Save first, then Test saved keys. The test calls the account endpoint; it does not launch an actor or certify remaining credits. The default actor is compass~crawler-google-places. A supplied token needs access to it and sufficient credits.

The entered list replaces the prior list; a blank field leaves it unchanged. Do not remove a key that owns an in-progress private actor run/dataset. Labels, request counts and failure statuses are shown without revealing token values.

## Gemini

Paste your API key and exact supported model ID, then Save Gemini. The shipped default is gemini-2.5-flash; choose a model currently available to your account with generateContent + Google Search support. Test saved key checks API access; model availability/search behavior is checked when research actually runs. The Step 2 prompt supplements the internal evidence/no-fabrication instructions, not the qualification code.

## Email

This connector supports SMTP for sending and IMAP over TLS for receiving, using a password or provider-issued app password. It does not implement OAuth. Organizational accounts that require OAuth cannot connect by entering their normal password; use a compatible mailbox or a future OAuth adapter.

Save a sender email, SMTP username, SMTP host, port and TLS security. The main mail password is copied to the IMAP password when provided, unless you enter a different IMAP password. Blank password fields preserve saved secrets. Changing the sender identity does not reroute already queued messages from an older sender; the app blocks those records.

### Gmail preset

For an eligible account, use Gmail's app-password flow (typically requiring 2-Step Verification). App passwords may not be available for every account, security configuration or administrator policy. Do not use your normal account password when Google requires another authentication method.

The preset fills SMTP smtp.gmail.com:587 with STARTTLS and IMAP imap.gmail.com:993. Enter your email address for the SMTP and IMAP usernames, and your eligible app password. Save, then test SMTP (no email sent) and IMAP login. A successful login does not guarantee inbox placement or recipient deliverability.

Official references:
- https://support.google.com/mail/answer/75726
- https://support.google.com/accounts/answer/185833
- https://support.google.com/a/answer/9003945

### Inbox settings

Enable inbox sync, enter IMAP host/username/port 993 and INBOX folder, and save. The background worker checks approximately every minute, or after clicking Check for replies. INBOX is the normal supported folder; simple folder names can be entered. Sync selects it read-only, uses UID/UIDVALIDITY checkpoints, and fetches with BODY.PEEK so it does not intentionally mark messages read or delete them.

On first connect, newest 100 messages are inspected. Later checks process newer UIDs, up to 100 per tick. Only messages from addresses contacted by this v2 sender account are imported. Messages over 2 MB are skipped and logged; attachments are not shown. Plain text is preferred; HTML-only messages are converted to text with scripts/styles removed and never executed.

Matched thread headers and sender address attach messages automatically. Same-address messages without a matching thread need manual linking. Recognized automatic messages do not increase the human reply counter. Other mail-client behaviors can produce unmatched mail; detection is not universal or a cryptographic identity check.

## Sending mode

Test only writes .eml files. Live SMTP sends after you review previews and confirm a batch. Every owner/business recipient gets its own message. Daily limits use UTC; midnight UTC is 5 AM in Karachi. Replies and first outreach share the live daily limit and delay. Test messages also participate in the shared delay.

Set your business mailing address and a reachable HTTPS public app URL for real recipients' unsubscribe links. A localhost URL only works on your own computer. This project does not automatically publish your laptop to the internet; local test mode is suitable until you deploy privately with HTTPS and secure operator access.

## Backups

Stop processes before copying data/. Back up data/vault.key and the SQLite database together. Restrict OS access to these files; local encryption does not defeat an attacker who can read both. UI secrets are not exported into Excel, logs or messages. Rotating a password is done by entering a new value and saving it; do not destroy the vault key to reset a connection.
